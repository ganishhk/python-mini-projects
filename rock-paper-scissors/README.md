# 🪨 Rock Paper Scissors

A command-line Rock Paper Scissors game built with Python.

## 📌 Features

- Play against the computer
- Random computer choice
- Five-round gameplay
- Keeps track of player and computer scores
- Displays the final winner

## 🛠️ Technologies Used

- Python 3
- random module

## 📚 Concepts Used

- Variables
- User Input
- Lists
- Loops
- Functions
- Conditional Statements
- Random Module

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/ganishhk/python-mini-projects.git
```

2. Navigate to the project folder

```bash
cd python-mini-projects/rock-paper-scissors
```

3. Run

```bash
python main.py
```
