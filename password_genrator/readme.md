# 🔐 Password Generator

A command-line Password Generator built with Python that creates random passwords using letters, numbers, and special characters.

---

## 📌 Features

- 🔢 User chooses password length
- 🔀 Generates a random password
- 🔤 Uses uppercase and lowercase letters
- 🔢 Includes digits
- 🔐 Includes special characters
- 📦 Organized using Python modules

---

## 🛠️ Technologies Used

- Python 3
- random module
- string module
