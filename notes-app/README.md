# 📝 Notes App

A command-line Notes App built with Python that allows users to create, read, and delete notes using file handling. The project is designed with a clean function-based structure to make the code modular, organized, and easy to maintain.

---

## 📌 Features

- ➕ Add new notes
- 📖 Read all saved notes
- 🗑️ Delete the notes file
- 🚪 Exit the application safely
- 📂 Store notes in a text file
- ✅ Check if the notes file exists before deleting
- 🔄 Menu-driven application

---

## 💻 Available Commands

| Command | Description |
|----------|-------------|
| `read` | Display all saved notes |
| `delete` | Delete the notes file |
| `exit` | Exit the application |
| Any other text | Save it as a new note |
