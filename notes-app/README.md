# 📝 Notes App

A command-line Notes App built with Python that allows users to create, read, clear, and delete notes using file handling.

## 📌 Features

- ➕ Add new notes
- 📖 Read all saved notes
- 🗑️ Delete the notes file
- 🧹 Clear all notes
- 🚪 Exit the application safely
- ✅ Checks if the file exists before deleting

## 🛠️ Technologies Used

- Python 3
- os module
- File Handling

## 📚 Concepts Used

- Variables
- User Input
- while Loop
- if-elif-else
- String Methods (`strip()`, `lower()`)
- File Handling (`with open()`)
- Read, Write and Append Modes
- os Module
- File Existence Checking

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/ganishhk/python-mini-projects.git
```

2. Navigate to the project folder

```bash
cd python-mini-projects/notes-app
```

3. Run the program

```bash
python main.py
```

## 💻 Available Commands

| Command | Description |
|----------|-------------|
| `read` | Display all saved notes |
| `clear` | Remove all notes from the file |
| `delete` | Delete the notes file |
| `exit` | Exit the application |
| Any other text | Save it as a new note |
