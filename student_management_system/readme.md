# 📚 Student Management System

A simple **Python CRUD (Create, Read, Update, Delete)** application that stores student records using **CSV files**. This project was built to practice Python fundamentals such as file handling, modules, functions, loops, and CSV operations.

---

## 🚀 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student
- ✏️ Update Student Information
- ❌ Delete Student Record

---

## 🛠️ Technologies Used

- Python 3
- CSV Module
- OS Module
- File Handling
- Functions
- Modules
