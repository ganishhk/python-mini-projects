# 🏦 Bank Account System

A Python Object-Oriented Programming (OOP) project that simulates a simple banking system. Users can create bank accounts, deposit money, withdraw money, transfer money between accounts, and check account balances.

---

## ✨ Features

- Create Bank Account
- Deposit Money
- Withdraw Money
- Transfer Money Between Accounts
- Check Account Balance
- Prevent Withdrawal When Balance Is Insufficient
- Prevent Negative Transactions

---

## 🧠 OOP Concepts Used

- Classes
- Objects
- Constructors (`__init__`)
- Instance Attributes
- Instance Methods
- Object Interaction
- Encapsulation Basics
- Conditional Logic

---

## 🚀 Example

```python
ganish = BankAccount("Ganish", 5000)
aman = BankAccount("Aman", 2500)

aman.transfer_money(ganish, 1000)

ganish.show_balance()
aman.show_balance()
```
