# 📊 Student Marks Analyzer

A command-line Student Marks Analyzer built with Python that helps analyze a student's marks by calculating statistics and checking the final result.

## 📌 Features

- ➕ Enter marks for multiple subjects
- 🏆 Find highest marks
- 📉 Find lowest marks
- ➕ Calculate total marks
- 📊 Calculate average marks
- ✅ Check PassFail status
- 📋 Display complete report

## 🛠️ Technologies Used

- Python 3

## 📚 Concepts Used

- Functions
- Parameters
- Return Statements
- Lists
- Loops
- Conditions
- User Input
- Built-in Functions (`max()`, `min()`, `sum()`, `len()`)

## 💻 Program Output

The program displays

- 📋 All entered marks

- 📉 Lowest marks
- ➕ Total marks
- 📊 Average marks
- ✅ Final Result (PassFail)
