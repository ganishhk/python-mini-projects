# 💰 Salary Tax Estimator

A simple Python program that estimates yearly income tax based on salary ranges.

## 📌 Features

- Takes yearly salary as input
- Calculates tax according to predefined slabs
- Displays tax percentage
- Displays tax amount

## 🛠️ Technologies Used

- Python 3

## 📚 Concepts Used

- Functions
- User Input
- Conditional Statements
- Arithmetic Operators
- Formatted Strings

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/ganishhk/python-mini-projects.git
```

2. Navigate to the project

```bash
cd python-mini-projects/salary-tax-estimator
```

3. Run

```bash
python main.py
```
