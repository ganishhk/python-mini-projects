# 🧮 Calculator

A command-line Calculator built with Python that performs basic arithmetic operations using functions.

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ⚠️ Division by zero handling
- 🔄 Menu-driven program

## 🛠️ Technologies Used

- Python 3

## 📚 Concepts Used

- Functions
- Parameters
- Return Statements
- Conditions
- Loops
- User Input

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/ganishhk/python-mini-projects.git
```

2. Navigate to the project folder

```bash
cd python-mini-projects/calculator
```

3. Run the program

```bash
python main.py
```
