# 🎓 Student Grade System

A command-line student grading system built with Python.

## 📌 Features

- Accepts multiple students
- Stores marks for four subjects
- Calculates total marks
- Assigns grades
- Calculates class average
- Sorts students based on marks
- Stores student data in a text file
- Exception handling for invalid input

## 🛠️ Technologies Used

- Python 3

## 📚 Concepts Used

- Dictionaries
- Lists
- Loops
- Functions
- File Handling
- Exception Handling
- Lambda Functions
- Sorting
- String Manipulation

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/ganishhk/python-mini-projects.git
```

2. Navigate to the project

```bash
cd python-mini-projects/student-grade-system
```

3. Run

```bash
python main.py
```
