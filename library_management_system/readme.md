# 📚 Library Management System

## 📖 Description

This is my first Object-Oriented Programming (OOP) project built with Python.

The project allows users to manage books in a library using a command-line interface. All book data is stored in a JSON file.

---

## 🚀 Features

- Add a new book
- View all books
- Search a book by ID or title
- Borrow a book
- Return a book
- Delete a book
- Store data permanently using JSON

---

## 🛠 Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
